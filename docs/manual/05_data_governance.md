# Data governance: licences, land, Indigenous data

> Status: outline. Learning goals, sections and exercises; the text is still to be written.

## You will learn

- Know why land status, governance and colonies are decided by people
- Read a data licence and what it allows
- Know the CARE principles for Indigenous data governance

## Sections

1. Licences: CC0, CC BY, CC BY-NC; what 'no licence' means
2. Land status: public, private, tribal land; who to ask
3. Indigenous data sovereignty and the CARE principles
4. Why the pipeline never fills these fields itself (hints only)
5. Case: Rumney Ranch and the open question of the Blackfeet Reservation; why the repository stays private

## Exercises

1. Find the licence of three open datasets in their records.
2. Read the site registry entry of a site and list what is still unknown.
