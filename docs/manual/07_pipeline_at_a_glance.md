# The pipeline at a glance

> Status: outline. Learning goals, sections and exercises; the text is still to be written.

## You will learn

- Know what milestone 1 does and does not do
- Name the stages and their outputs
- Know where every output goes

## Sections

1. Milestone 1: find, download, describe, catalogue, check; and reorganise field drives
2. What it does not do: process, reproject, co-register, assign colonies, display (milestones 2-8)
3. Stages: source → summary → build → curate → root catalogue
4. Data roots and outputs: `open_datasets/`, `beaver_dataset/`, `stac/`, `output/dataset/`
5. Code layout: catalog, readers, sources, steps, summaries, field_layouts

## Exercises

1. Draw the pipeline for one dataset, naming the command and the file each stage writes.
2. Find the root catalogue of the open datasets and list its sites.
