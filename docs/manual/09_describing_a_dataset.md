# Describing a dataset: summaries and Claude

> Status: outline. Learning goals, sections and exercises; the text is still to be written.

## You will learn

- Read and write a dataset summary
- Draft one with Claude Code and review it
- Know what review means and how it is recorded

## Sections

1. The summary file: groups, files, products, roles, dates, notes, evidence, open questions
2. Evidence: what code reads for sure
3. Drafting with Claude Code (`describe prompt`), checking (`describe check`)
4. Reviewing: what to check, `reviewed: {by, date}`
5. Open questions and hints

## Exercises

1. Write a summary for the sample data root by hand and make it pass the check.
2. Draft one with Claude for the downloaded dataset; review it.
